Privacidad: qué sale de tu navegador
Tu clave

Se guarda en el almacenamiento local de este navegador y solo se envía a Google. Puedes borrarla cuando quieras.

Lo que analizas

Los logs, incidentes y perfiles van a la API de Gemini con tu clave. En el nivel gratuito Google puede usarlos para mejorar sus modelos: anonimiza los datos reales.

Geolocalización

Solo las IP públicas detectadas en tus logs se consultan en ipwho.is (o ipapi.is si falla), y puedes desactivarlo.

Sin servidor propio

Es una web estática en GitHub Pages: no hay base de datos, ni cuentas, ni analítica.
